# 作为 API 后处理可选项

数据顺序：原图+bbox+类型 → 图像 API 生成 mask → 按上传画布/裁剪/拼图记录还原 → 原尺寸二值化与 bbox 校验 → 视觉模型判断 → 仅确认整体偏移的实例调用复位 → 查看候选再复核 → 导出选用的 mask、叠加图和更新后的 JSON。

`SKILL.md` 是调用方模型的操作说明，不会被图像 API 自动执行。工具可供有视觉与脚本执行能力的 Codex/agent 使用；VS Code 的普通 Python 批处理若要自动判断，还需配置能读取原图及叠加图、输出结构化判定的视觉模型，并按本 skill 编排两次判断。只有图像生成接口时，可以先人工填写判定文件，不能假定该接口也提供可靠的文字视觉判定。此包不增加付费 API 请求，不假定现有供应商支持工具调用。

建议在 API 程序中把该阶段配置为 `crack_realign.enabled`，默认关闭，以便保留 image2.5 与 image2.5+复位两种实验条件。启用时：

1. 把 API 原稿另存，生成每个 C/M 实例的原图及叠加局部，给判定模型读取；其余缺陷沿用原稿。
2. 执行 `propose`，只对满足判定条件的实例调用复位。记录 `solver_called`、候选移动量与 `solver_seconds`。
3. 对 `algorithm_shifted=true` 的候选做后复核，再执行 `finalize`。
4. 使用 `final/instance_masks/` 重算导出数据；面积、RLE、哈希和总 mask 必须对应最终文件。模型判断费用和 token 与生成费用分开记录，无法取得时为 null。

依赖：`numpy`、`Pillow`；实际调用复位时还需 `opencv-python`。前后判断可复用原有视觉 agent，也可用单独的视觉 API，但须固定判定提示与模型版本，记录时间/用量。工具运行在新目录，不覆盖原实验，不读取参考 mask。

算法默认搜索范围为原图各轴 ±24 像素，至少保留 98% 前景；记录裁剪损失，必要时设 `--min-kept 1` 禁止丢失前景。旧规则要求分数增益至少 0.08、位移至少 2 像素；分段规则要求增益至少 0.04、分段增益中位数至少 0.02、至少 62.5% 有效分段提高，且两种候选距离不超过 1.5 原图像素。分段规则仅额外用于较细 mask（距离变换90分位 ≤4 像素，为半宽尺度）。这些是工程门槛，不是准确率或模型置信度。

当前复位器对整体平移有一定帮助；线宽、分支、形状差异、目标选择错误和局部变形需要其他方法。现有小样本的同批改进不能当作新的独立准确率结论。
