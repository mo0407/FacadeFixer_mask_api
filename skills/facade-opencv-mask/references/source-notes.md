# 方法来源与实现边界

参考：[墙面缺陷 Mask 生成方法对比](https://www.yuque.com/moshaojie-imc9t/wwn8y6/ekdll0gxu1l4ph20)，文档日期2026-09-11，2026-09-29通过用户授权的语雀API读取。凭证未写入skill及程序。

文档将视觉辅助像素求解与 FacadeFixer 模型流程分开：前者额外使用逐图引导线、轮廓和排除区；后者以检测类别、训练权重及分割提示为主要先验。本skill据此修正了“OpenCV”只有bbox自动阈值一种方式的局限，保留自动基线，新增 assisted 模式。

文档列出的旧辅助代码（segment_assisted.py、build_guides.py等）未在本次限定搜索中找到；新增 guided.py 是按文档方法重新实现，不宣称复制或完全复现旧代码。已验证合成行为，尚未重新跑50张逐图引导数据。

文档关于 FacadeFixer 的类别匹配、SAM提示、裂缝模型融合、默认阈值等是当时静态代码分析。本次未重新验证该项目运行环境、权重或现行代码，不把这些描述作为已可调用的功能。本skill没有集成SAM、CrackSAM、SegFormer等模型。

新增吸收的经验：

- 引导由助手看原图估计，不是用户逐点操作，也不是bbox自动产生。早期按行追踪主要针对竖裂，后期曲线法支持任意方向和分支，不混用两代参数。
- 历史47张使用新引导，前3张沿用旧mask；必须逐图区分 carried_forward 与 regenerated，而非将整批称为同条件盲测。
- 锈迹对粉色、米色底面使用HSV加R−G/R−B限制；这些差值以有符号数计算，避免uint8相减溢出。
- 深色饰面上的黑斑按局部明暗阈值选择，不因为颜色深就把整个饰面填白。外观黑斑不证明成因是霉菌、渗漏或污染。
- 独立起皮多块合并时不能只保留全图最大连通块；薄片浅色卷边也可能属于目标。GrabCut确定前景内的错误不能期待自动消除。
- 杂物细带可复用路径算法，类别不改成裂缝；衣架内背景用排除区保留。被遮挡的裂缝不臆测补齐。

旧任务中的固定坐标和样本阈值没有复制进通用默认配置。历史结论用于方法设计，新脚本是独立实现；本次没有宣称其输出与旧实现完全一致。
