# 按类别分割：方法论与边界

|类型|像素证据与处理|常见错误|改进方向|
|---|---|---|---|
|C 线性裂缝 / M 网裂|灰度轻度平滑，多尺度 black-hat 提取细暗线，自适应阈值，连通域长度/形状过滤；原分辨率|规则接缝、管道边缘、粗糙纹理被当裂缝；低对比细裂缝漏检|多方向脊线、边缘配对、局部交互种子；不要强开运算切断1像素线|
|T 锈迹 / R 腐蚀|HSV 红橙棕区间与 Lab a/b，过滤低饱和背景，小孔填充|红漆、砖块、棕色基材误检；灰黑腐蚀漏检|区分金属/墙面范围，局部白平衡；单靠颜色不能确认腐蚀|
|D 墙面污渍 / L 渗漏痕迹|暗色 Otsu + 局部灰度残差；渗漏追加棕黄证据|阴影、窗洞、材料本色混淆；白色析出物可能漏检|限制到墙面，光照校正，多颜色子类型；不把所有暗像素都认作污渍|
|D / GroundLitter|以地面主色为背景，Lab色差、较亮/高色度像素作为散落物|深色布料漏检、亮色地面误检|语义种子/人工标记或模型辅助；不能把污垢地面填白代替垃圾|
|V 植物|绿色 HSV，加深色枯叶证据，连通域过滤|黑色阴影、墙缘、背景草木混入|bbox与前景种子结合；细叶避免大核形态学|
|P 涂层剥落 / S 破损|Lab聚类，以bbox边缘主色估计完好背景，颜色差异种子驱动 GrabCut，小孔填充|框边缘已全是损伤时前后景倒置；混合基材、深腔、阴影混淆|额外上下文环、明确前景/背景种子；空洞内部算损伤时不能只保留高对比外缘|

## 参数的尺度

阈值、核尺寸须按 ROI 像素尺度记录，不把一张图的固定 x/y 推广给全批数据。裂缝不能为加速随意缩小；区域缺陷可缩小后最近邻还原，代价是边缘精度。闭运算只能连接合理小间断，不能跨越远处污点把多实例合成矩形。

## 不确定性

bbox 是空间限制而非完整前景；类别告诉程序寻找什么外观，但未提供可靠前景种子。仅bbox+类型不足以唯一确定所有像素边界，特别是剥落、破损和阴影。纯CV结果应是可重复基线，不通过隐含人工描边伪装自动分割。

## Hybrid 后处理

获授权后，可将模型 mask 膨胀为小搜索带，在原图中找细暗线/色差边界；或用腐蚀前景和外部背景初始化 GrabCut。记录膨胀半径、阈值、缩放、每个实例的来源，保存 raw/refined 两份。搜索带不能找回远离模型候选区的漏检；模型漏了对象时应重新检测，不能只做形态学。

## 评估

同一批图统一bbox和类型，冻结输入哈希；实例IoU/Dice按id匹配，类别指标先在单图内求同类mask并集以免重叠重复计数。分别报告宏平均和像素合并统计，并查看小裂缝被大区域面积掩盖的问题。模型候选标注、尤其含CV修正的参考，不是独立真值。最终准确率需要人工复核标签与独立留出集。
